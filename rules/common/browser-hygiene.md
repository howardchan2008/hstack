# Browser Hygiene

## Tab Cleanup (MANDATORY)

After completing any browser-based task, **close every tab you opened** before returning results to the user.

### Rules

- Close tabs immediately after extracting the needed information or completing the action.
- If multiple tabs were opened during a task, close all of them - not just the last one.
- Never leave tabs open "for reference." If the information is needed later, capture it in the response or a file.
- If a tab was already open before the task started, leave it alone - only close tabs you opened.

### Why

Open tabs consume memory and CPU. Accumulated tabs from agent work degrade browser performance over time.
